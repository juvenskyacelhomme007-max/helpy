# HElPY - Marketplace & Services Platform for Haiti

HElPY is a mobile-first marketplace platform designed for Haiti. It allows users to create accounts, list products, services, real estate, vehicles, and businesses, contact sellers via phone or WhatsApp, and leave reviews.

## Features
- Complete User Auth (Register/Login via REST API)
- Mobile-first responsive UI optimized for Android
- Multi-category Unified Listing Management (CRUD)
- Business Directory with Reviews
- Parameterized SQL Search across products, services, businesses
- Railway PostgreSQL Integration

## Setup Local
1. `npm install`
2. Configure `DATABASE_URL` environment variable.
3. Run `npm start`
4. Access `http://localhost:3000`
