# HELPY — interface corrigee

Cette version met l'accueil au style de la maquette fournie :
- interface mobile-first sombre avec accents violet HELPY
- header notifications/profil
- hero moderne
- recherche + filtres
- 6 categories avec icones
- cartes d'entreprises responsive
- section professionnel
- navigation fixe en bas
- `add-business.html` ajoute pour corriger la route `/add-business`

Le frontend accepte les reponses `entreprises`, `businesses`, `data` ou un tableau direct depuis `/api/businesses`.

IMPORTANT : le `server.js` de ce ZIP est l'ancien backend en memoire du ZIP original. Ne remplace pas ton backend PostgreSQL Railway actuel avec celui-ci si tu veux conserver la base de donnees.
